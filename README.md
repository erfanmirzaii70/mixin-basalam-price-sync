# راهنمای راه‌اندازی هماهنگ‌سازی قیمت (میکسین ← باسلام)

اسکریپت فقط از سایت می‌خونه (GET) و فقط تو باسلام می‌نویسه. قیمت سایت هیچ‌وقت عوض نمی‌شه.

## ۱) فایل‌ها رو تو ریپو بذار
- `sync_prices.py` و `mapping_overrides.json` ← تو ریشه ریپو (Add file ← Upload files)
- `.github/workflows/sync_prices.yml` ← Add file ← Create new file، اسم کامل بالا رو بنویس و محتوا رو پیست کن

## ۲) سکرت‌ها (Settings ← Secrets and variables ← Actions ← Secrets)
| اسم | مقدار |
|---|---|
| MIXIN_BASE_URL | آدرس سایت، مثل https://partzune.ir (بدون / آخر) |
| MIXIN_API_KEY | کلید API میکسین |
| BASALAM_TOKEN | توکن باسلام (فقط مشاهده/ویرایش محصول + مشاهده غرفه) |
| BASALAM_REFRESH_TOKEN | اختیاری |
| TELEGRAM_BOT_TOKEN | توکن ربات |
| TELEGRAM_CHAT_ID | آی‌دی چت خودت |

## ۳) اجرای آزمایشی (پیش‌فرض)
Actions ← Sync prices to Basalam ← Run workflow.
چیزی تو باسلام عوض نمی‌شه. تو تلگرام خلاصه + فایل `mapping_report.csv` میاد.
فایل رو باز کن: ستون `action` رو ببین (change / same / not on Basalam / needs approval / BLOCKED).

## ۴) اصلاح جفت‌نشده‌ها
اگه محصولی جفت نشد یا اشتباه جفت شد، تو `mapping_overrides.json` بنویس:
```json
{ "123": 456789, "124": null }
```
(آی‌دی محصول سایت ← آی‌دی محصول باسلام؛ `null` یعنی نادیده بگیر)

## ۵) فعال‌سازی واقعی
Settings ← Secrets and variables ← Actions ← تب **Variables** ← New repository variable:
اسم `DRY_RUN` مقدار `0`. از این به بعد هر ۱۵ دقیقه چک می‌کنه و فقط وقتی قیمتی عوض شد یا خطا بود تو تلگرام پیام می‌ده.

## نکته‌ها
- تغییر بیشتر از ۴۰٪ اعمال نمی‌شه و تو تلگرام «BLOCKED» می‌خوره.
- اگه تو باسلام تخفیف فعال داری، قیمت اصلی عوض می‌شه، قیمت نهایی با تخفیف حساب می‌شه.
- محصولاتی که تنوع‌شون تو سایت و باسلام فرق داره رد می‌شن (تو گزارش می‌بینی).
- گیت‌هاب بعد از ۶۰ روز بی‌فعالیتی ریپو، زمان‌بندی رو خاموش می‌کنه (فقط ریپوی عمومی). یه بار Run workflow بزن تا دوباره فعال شه.
- زمان‌بندی گیت‌هاب ممکنه چند دقیقه دیر اجرا شه.
- اگه نصب `basalam-sdk` خطا داد، همون خط نصب رو از `own_basalam.yml` قبلی خودت کپی کن.

---
## توکن باسلام چیه؟
همون «توکن شخصی» (Personal Token) که از بخش API/توسعه‌دهندگان باسلام می‌سازی، همونجایی که قبلاً توکن ساخته بودی. دسترسی‌ها: «مشاهده و ویرایش محصول» و «مشاهده اطلاعات غرفه». مقدارش رو تو سکرت `BASALAM_TOKEN` بذار.

## آدرس سایت (MIXIN_BASE_URL)
بله، آدرس سایتته: `https://partzune.ir` (بدون / آخر).

## دستور تلگرام
تو چت با ربات بنویس: **تغییر بده**  (یا `/sync`)
- ربات جواب «دارم هماهنگ می‌کنم» می‌ده، بعد نتیجه رو می‌فرسته (حتی اگه تغییری نبود).
- چون گیت‌هاب هر ۵ دقیقه چک می‌کنه، جواب بین ۱ تا ۱۰ دقیقه طول می‌کشه، نه فوری.
- فقط پیام از چت خودت (TELEGRAM_CHAT_ID) قبول می‌شه.
- اگه این ربات رو برای اتوماسیون دیگه‌ای (webhook یا getUpdates) استفاده می‌کنی، تداخل پیدا می‌کنه. بهتره یه ربات جدا از BotFather بسازی.
- تا وقتی `DRY_RUN` برابر `0` نشده، دستور فقط گزارش آزمایشی می‌ده.
